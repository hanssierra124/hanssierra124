# Cómo activar tu perfil de GitHub

1. En GitHub, crea un repositorio **público** llamado exactamente `hanssierra124` (igual que tu usuario). GitHub te avisará: "You found a secret!".
2. Sube a ese repositorio **todo el contenido de esta carpeta**: `README.md`, `banner.svg`, `stack.svg` y las carpetas `badges/`, `stickers/`, `titles/`, `stats/`, `scripts/` y `.github/` (Add file → Upload files → arrastra todo → Commit). La carpeta `.github` empieza con punto: si tu explorador la oculta, actívale "mostrar archivos ocultos".
3. Ve a la pestaña **Actions** del repo, abre "Actualizar tarjetas de estadísticas" y pulsa **Run workflow**. En un minuto las tarjetas tendrán tus datos reales y se actualizarán solas cada día.
4. Abre `README.md` y cambia las líneas marcadas con `EDITA`:
   - Enlaces de LinkedIn, YouTube e Instagram (`TU_USUARIO`, `TU_CANAL`) y la URL del portfolio.
   - El stack está dibujado en `stack.svg`: pásale a Claude tu lista de tecnologías y lo regenera.
5. Entra a github.com/hanssierra124: el README aparece arriba de tus repos.

## Extras
- **Foto de perfil:** Settings → Public profile → Profile picture. Una foto con fondo azul profundo (#1B1B4E) combina con el banner.
- **Bio:** `Fullstack · AI Engineer · Creador de contenido. Build · Ship · Repeat.`
- **Repos fijados:** en tu perfil, "Customize your pins" y elige hasta 6 proyectos (los mismos del portfolio).
- Las tarjetas de `stats/` traen datos de ejemplo hasta que corra la acción del paso 3.
